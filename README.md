# 🏛️ Fullstack Template
Template для Fullstack приложений на базе FastAPI + React.js

## 💫 Стек технологий
Backend:
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- asyncpg

Frontend:
- React.js
- Tailwind CSS
- Vue.js

## ⚡ Разворачивание приложения
1) Заполните `.env` согласно шаблону `.env.example`
2) Напишите в терминале `docker compose up -d`
3) Готово!
